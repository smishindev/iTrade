## P5.1 API для интерфейса

### [ ] P5.1.01 · 🤖 Статус системы · 2 ч
**Шаги:** `GET /api/status`: режим PAPER/LIVE, маскированный счёт, подключения (БД, IB Gateway), готовность данных на дату,
время последней сверки, режим риска, «готов к торговле: да / нет и почему».
**Готово, когда:** интеграционный тест на каждую причину «не готов».

### [ ] P5.1.02 · 🤖 Сканирование и идеи · 2 ч · после: P4.2.02
**Шаги:** задание «после закрытия» запускает стратегию на текущих данных → таблицы `signals` (все идеи, включая отклонённые риском, с причинами);
`GET /api/signals?date=`.
**Готово, когда:** повтор задания за ту же дату не создаёт дублей.

### [ ] P5.1.03 · 🤖 Данные карточки идеи · 2 ч · после: P5.1.02
**Шаги:** `GET /api/signals/{id}`: бары для графика (1 год), SMA200, SMA5, лимит, стоп; размер, издержки в $, ₪ и R;
статистика версии стратегии из исследований (N, ожидаемый R с интервалом, доля выигрышей, просадка, худшая серия);
предупреждения (ex-div, возраст данных, исполнимость долей).
**Готово, когда:** тест на полноту ответа; статистика берётся из записанного исследования, а не считается на лету.

### [ ] P5.1.04 · 🤖 Решения по идеям · 2 ч · после: P5.1.02
**Шаги:** `POST /api/signals/{id}/decision` (принять / отклонить, причина обязательна, ключ идемпотентности);
принятие → `trade_intent` с утверждёнными границами (лимит, стоп, макс. риск, срок до отсечки); таблица `signal_decisions`.
**Готово, когда:** повторный запрос с тем же ключом возвращает тот же результат; без причины — 400.

### [ ] P5.1.05 · 🤖 Позиции, заявки, исполнения · 1,5 ч
**Готово, когда:** `GET` для позиций, заявок (с состояниями), исполнений; данные из `FakeBrokerGateway`.

### [ ] P5.1.06 · 🤖 Исследования, журнал, экспорт · 1,5 ч · после: P4.5.01
**Готово, когда:** `GET` для запусков исследований и их метрик; журнал решений и денежных событий; скачивание экспорта.

### [ ] P5.1.07 · 🤖 События SignalR · 1,5 ч · после: P2.4.04
**Шаги:** события: изменение состояния заявки, исполнение, сверка, соединение, режим риска → TanStack Query инвалидирует нужные запросы.
**Готово, когда:** тест: событие из Fake-брокера доходит до клиента.

## P5.2 Экраны

### [ ] P5.2.01 · 🤖 Шапка · 1,5 ч · после: P5.1.01
**Готово, когда:** на каждой странице: крупная плашка PAPER/LIVE (разные цвета), маскированный счёт, время сверки, режим риска, состояние подключений.

### [ ] P5.2.02 · 🤖 Обзор · 2 ч · после: P5.2.01
**Готово, когда:** капитал в $ и ₪, открытый риск, позиции кратко, проблемы, «готов к торговле» с причинами.

### [ ] P5.2.03 · 🤖 Список идей · 2 ч · после: P5.1.02
**Готово, когда:** все идеи дня (TanStack Table), статус, причины отклонения риском, фильтры; история прошлых дней.

### [ ] P5.2.04 · 🤖 Карточка: график · 2 ч · после: P5.1.03
**Шаги:** Lightweight Charts: свечи, SMA200, SMA5, линии лимита и стопа, маркеры прошлых сделок; атрибуция по лицензии.
**Готово, когда:** график корректен на 3 примерах (проверка глазами + снапшот-тест данных).

### [ ] P5.2.05 · 🤖 Карточка: риск, издержки, статистика, предупреждения · 2 ч · после: P5.2.04
**Готово, когда:** суммы в $, ₪ и R; статистика с размером выборки и интервалом; нет «вероятности заработать».

### [ ] P5.2.06 · 🤖 Принятие и отклонение · 2 ч · после: P5.1.04, P5.2.05
**Шаги:** форма (причина обязательна), диалог подтверждения с итогом (сумма, комиссия, риск в ₪, режим PAPER/LIVE); блокировка двойного клика.
**Готово, когда:** Vitest на форму; повторный клик не создаёт второе намерение.

### [ ] P5.2.07 · 🤖 Позиции и заявки · 2 ч · после: P5.1.05
**Шаги:** позиции, входы, защита (статус «защищена» только по данным брокера), выходы, исполнения, ошибки; кнопки «Пауза» и «Закрыть позиции» (подключаются в P6.4.06).
**Готово, когда:** состояния заявок отображаются по машине состояний PLAN §7.3.

### [ ] P5.2.08 · 🤖 Исследования · 2 ч · после: P5.1.06
**Готово, когда:** список запусков, сравнение вариантов, отметка финального запуска, ссылка на отчёт.

### [ ] P5.2.09 · 🤖 Журнал и отчёты · 2 ч · после: P5.1.06
**Готово, когда:** все решения, денежные события, сверки, налоговый резерв (заглушка до P7.4), экспорт.
