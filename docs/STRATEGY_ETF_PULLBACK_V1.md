_Зафиксирована 7 октября 2026 года, **до первого запуска бэктеста**. Параметры —
[`config/strategies/etf_pullback_v1.toml`](../config/strategies/etf_pullback_v1.toml); версия стратегии —
SHA-256 канонического JSON этого файла (TOML → JSON с отсортированными ключами, разделители `,` и `:` без пробелов,
UTF-8, даты как строки ISO). **Версия на 7 октября 2026: `0bd2d34b9adae047cf9488127b640cd47841b0a406041329436016bc6ebc9070`.** Документ обязателен для обеих реализаций (Python — проверка A и
эталон, C# — ядро платформы): при расхождении документа и кода прав документ, код исправляется.
Изменение правила = новая версия стратегии и новая запись в `docs/research-log.md`._

**Гипотеза.** У ликвидных американских ETF в восходящем тренде резкая краткосрочная перепроданность
(RSI(2) ≤ 10) чаще восстанавливается за несколько сессий, чем продолжается. Покупка на следующем открытии и
выход при возврате выше короткой средней дают положительный ожидаемый результат в R **после издержек
на реальном размере счёта** и лучше случайного входа с теми же фильтрами и выходами.

## 1. Обозначения и данные

| Обозначение | Значение |
|---|---|
| *t* | торговая сессия NYSE (календарь XNYS), решение принимается после её закрытия |
| *t+1* | следующая сессия по календарю XNYS |
| `O_t, H_t, L_t, C_t` | цены открытия, максимум, минимум, закрытие сессии *t*, **скорректированные на сплиты, без дивидендной корректировки** (поля `open/high/low/close` снимка Yahoo) |
| `V_t` | объём, скорректированный на сплиты (поле `volume`) |
| `D_t` | дивиденд на акцию с экс-датой *t* (поле `dividends`, 0 если нет) |
| `K_t` | коэффициент сплита с экс-датой *t* (поле `splits`, 0 если нет; 2:1 → 2) |
| `adj_close` | **не используется** ни в сигналах, ни в доходности (дивиденды учитываются деньгами, §6.4) |

**Источник:** курированные снимки `itrade ingest` (Yahoo), каждый со SHA-256 в manifest; снимок данных
фиксируется для запуска (хэш в отчёте). Строки, не прошедшие проверки качества, в расчёт не попадают.

**Сырые (исторические) цены** для исполнения, количества и комиссий:
`S(d)` = произведение `K_x` всех сплитов с экс-датой *x* > *d*, известных в снимке (1, если их нет);
сырая цена = скорректированная × `S(d)`; сырое количество = скорректированное / `S(d)`.
Индикаторы считаются на скорректированных ценах (отношения от масштаба не зависят);
уровни заявок на дату *t* переводятся в сырые цены множителем `S(t)`.

## 2. Индикаторы

Все индикаторы считаются по ряду инструмента **с первого бара снимка**, в порядке дат, только по барам ≤ *t*.
До накопления нужного числа баров значение **не определено** (NaN / null), а не 0.
Арифметика — двойная точность в индикаторах, `decimal` — в деньгах и количествах (§6).

### 2.1 SMA(n)
`SMA_n(t) = (C_{t−n+1} + … + C_t) / n`; определена, начиная с *n*-го бара.

### 2.2 RSI(n) по Уайлдеру
1. `Δ_i = C_i − C_{i−1}` для *i* ≥ 1 (у первого бара Δ нет).
2. `G_i = max(Δ_i, 0)`, `Λ_i = max(−Δ_i, 0)`.
3. Начальные значения на баре *i = n*: `AG_n = (G_1 + … + G_n) / n`, `AL_n = (Λ_1 + … + Λ_n) / n`.
4. Далее для *i > n*: `AG_i = (AG_{i−1}·(n−1) + G_i) / n`, `AL_i = (AL_{i−1}·(n−1) + Λ_i) / n`.
5. `RSI_i = 100 − 100 / (1 + AG_i / AL_i)`; если `AL_i = 0` и `AG_i > 0` → 100; если `AL_i = 0` и `AG_i = 0` → 50.
6. RSI определён, начиная с бара *n* (нужно *n+1* закрытий).

### 2.3 ATR(n) по Уайлдеру
1. `TR_i = max(H_i − L_i, |H_i − C_{i−1}|, |L_i − C_{i−1}|)` для *i* ≥ 1.
2. Начальное значение на баре *n*: `ATR_n = (TR_1 + … + TR_n) / n`.
3. Далее: `ATR_i = (ATR_{i−1}·(n−1) + TR_i) / n`.

### 2.4 Средний долларовый оборот
`ADV_w(t) = (1/w) · Σ_{i=t−w+1..t} C_i · V_i` (скорректированная цена × скорректированный объём = сырой оборот в $).

## 3. Набор инструментов

Кандидаты — [`config/universes/etf_pullback_v1.toml`](../config/universes/etf_pullback_v1.toml) (задача P1.A.03):
обычные ETF, без плечевых, обратных и ETN; у каждого указана **группа связанности** (§5.3).

Инструмент **входит в набор на дату t**, если одновременно:
1. в снимке есть не меньше `min_history_sessions` = **756** баров с датой ≤ *t*;
2. `ADV_20(t) ≥` **$50 000 000**;
3. на *t* у инструмента нет непройденной проверки качества и он не остановлен из-за противоречивого корпоративного события.

Членство пересчитывается каждую сессию; выход из набора не закрывает открытую позицию, а только запрещает новые входы.

## 4. Сигналы (после закрытия сессии *t*)

### 4.1 Вход
Инструмент даёт сигнал входа на *t*, если одновременно:
1. он в наборе на *t* (§3);
2. `C_t > SMA_200(t)`;
3. `RSI_2(t) ≤ 10`;
4. по нему нет открытой позиции и нет висящей входной заявки;
5. сессия *t+1* **не** является его экс-дивидендной датой (`D_{t+1} = 0`).
   _Допущение: экс-даты объявляются заранее и на момент t известны._

Уровни (скорректированный масштаб на *t*, затем × `S(t)` в сырые цены, округление до `tick_size` = $0,01):
- **лимит** `Lim = floor_tick(C_t + 0,5 · ATR_14(t))`;
- **стоп** `Stp = floor_tick(C_t − 2,0 · ATR_14(t))`;
- сигнал отбрасывается с причиной `invalid_levels`, если `Stp ≤ 0` или `Lim ≤ Stp`.

### 4.2 Порядок сигналов
1. по возрастанию `RSI_2(t)`;
2. при равенстве — по убыванию `ADV_20(t)`;
3. при равенстве — по тикеру (лексикографически).

Сигналы обрабатываются в этом порядке; каждый следующий видит лимиты и резервы, занятые предыдущими (§5).

### 4.3 Выход
Для каждой открытой позиции после закрытия сессии *t* (`h` — номер сессии удержания, сессия входа = 1):
- `C_t > SMA_5(t)` → продажа **на открытии t+1** (причина `exit_sma`);
- иначе `h ≥ max_hold_sessions` = **10** → продажа на открытии *t+1* (причина `max_hold`);
- выход по сигналу в сессию входа **возможен** только после её закрытия, то есть исполнится не раньше
  открытия следующей сессии; в саму сессию входа позиция может закрыться только стопом.

## 5. Размер позиции и риск-лимиты

### 5.1 Капитал и бюджет
- `E_t` — стоимость счёта на закрытие *t*: все деньги (расчётные и нерасчётные) + Σ количество × сырое `C_t`.
- Начальный капитал — `initial_capital_usd` = **$3 280**; пополнений и выводов в бэктесте нет.
- Бюджет риска сделки `B = 0,0025 · E_t` (0,25%).

### 5.2 Количество
- Гранулярность `g`: 1 для `whole`, `fractional_step` = 0,0001 для `fractional`.
- Риск на акцию с переменными издержками: `r = (Lim − Stp) + Lim · 2 · (hs + sl) / 10⁴`,
  где `hs` — `half_spread_bps` инструмента (из файла набора, иначе `default_half_spread_bps`), `sl` — `slippage_bps` из `config/costs.toml`.
- Начальное `q = floor_g((B − 2 · min_per_order_usd) / r)`.
- Затем, пока `q > 0` и `q · (Lim − Stp) + RT(q) > B`, уменьшать `q` на `g`, где `RT(q)` — ожидаемые издержки полного
  цикла (покупка по `Lim` + продажа по `Stp`) по модели издержек (`itrade.costs.estimate_trade_cost`).

### 5.3 Ограничения (каждое уменьшает `q` до допустимого, проверяются по порядку)
| # | Ограничение | Причина пропуска при `q = 0` |
|---|---|---|
| 1 | `q · Lim ≤ 0,20 · E_t` | `max_position` |
| 2 | `q · Lim ≤ $700` | `max_order_notional` |
| 3 | Σ (открытый риск позиций `q_i·(вход_i − стоп_i)` + риск висящих входов) + `q · (Lim − Stp) ≤ 0,0075 · E_t` | `max_total_risk` |
| 4 | Σ (стоимость позиций по `C_t` + номинал висящих входов) + `q · Lim ≤ 0,60 · E_t` | `max_invested` |
| 5 | то же только для инструментов той же группы `≤ 0,30 · E_t` | `max_group` |
| 6 | `q · Lim + RT(q)/2 ≤` доступные **расчётные** деньги минус резервы | `settled_cash` |
| 7 | число позиций + висящих входов `< 3` | `max_positions` (сигнал пропускается целиком) |
| 8 | `RT(q) ≤ 0,15 · q · (Lim − Stp)` | `cost_too_high` |
| — | `q` после округления = 0 | `size_zero` |

Каждый пропущенный сигнал записывается с причиной. Принятый сигнал **резервирует** `q · Lim + RT(q)/2` расчётных денег до исполнения или снятия заявки.

## 6. Модель исполнения (бэктест)

### 6.1 Порядок событий в сессии *d*
1. **Открытие.** Сначала выходы (MOO), затем входы (LOO) — в порядке §4.2.
2. **Внутри дня.** Стопы всех открытых позиций, включая открытые сегодня.
3. **Закрытие.** Дивиденды и сплиты с экс-датой *d*; оценка `E_d`; сигналы выхода, затем входа → заявки на *d+1*.
4. Неисполненные входные заявки снимаются после открытия *d* (резерв освобождается).

### 6.2 Цены исполнения (сырые цены сессии *d*)
| Заявка | Условие | Цена |
|---|---|---|
| Вход LOO | `O_d ≤ Lim` | `O_d` |
| Вход LOO | `O_d > Lim` | не исполнена (причина `limit_not_reached`) |
| Выход MOO | всегда | `O_d` |
| Стоп | `O_d ≤ Stp` | `O_d` (гэп) |
| Стоп | иначе `L_d ≤ Stp` | `Stp` |

Если выход MOO и стоп приходятся на одно открытие, исполняется одна продажа по `O_d` (OCA), причина — `stop_gap` при `O_d ≤ Stp`, иначе причина выхода.
Спред и проскальзывание **не** закладываются в цену: они входят в издержки модели (§6.3) — без двойного учёта.

### 6.3 Издержки
Каждая заявка оценивается `estimate_trade_cost` (`config/costs.toml`, IBKR Pro Tiered) с фактическим количеством и ценой:
комиссия с минимумом и потолком, сборы SEC и FINRA на продажах, `half_spread_bps` инструмента, `slippage_bps`.
Конвертация валюты в бэктесте не начисляется (счёт в USD, депозит конвертирован один раз).

### 6.4 Дивиденды и сплиты
- Дивиденд: позиция, открытая на закрытие *d−1*, получает `q · D_d · S(d) · (1 − 0,25)` деньгами в сессию *d*
  (дата выплаты не моделируется).
- Сплит с экс-датой *d*: сырое количество × `K_d`, сырые стоп и вход ÷ `K_d` (брокер корректирует заявки — проверяется в P1.B).

### 6.5 Расчёты по сделкам
Деньги от продажи становятся расчётными через `days` сессий XNYS по циклу из `[simulation].settlement`
(T+3 до 2017-09-04, T+2 до 2024-05-27, T+1 с 2024-05-28). Покупки — только на расчётные деньги (§5.3 п. 6).

### 6.6 Концы периодов
Сигналы генерируются только внутри периода. Позиции, открытые на последнюю сессию периода, закрываются
по её закрытию `C` с издержками (причина `end_of_period`). Индикаторы считаются по всем данным до *t* (прогрев не обрезается).

## 7. Метрики

**R сделки** = (сырые выручка продаж − стоимость покупки − все издержки сделки + дивиденды) / `(вход − Stp) · q`,
где знаменатель — плановый риск по фактической цене входа.

Обязательные метрики отчёта — по навыку `research-integrity`: число сделок; ожидаемый R с 90% бутстрэп-интервалом
(10 000 выборок, seed = `base_seed`); доля выигрышей с интервалом Уилсона; средние выигрыш и проигрыш в R;
издержки в R; максимальная просадка `E` и её длительность; худшая серия; доля исполнимых сигналов и причины пропусков;
разбивка по годам, инструментам, группам; перцентиль случайного контроля; рыночный ориентир (покупка и удержание SPY с дивидендами).

## 10. Случайный контроль

1 000 прогонов, seed прогона *k* = `base_seed + k`. В каждом прогоне: тот же набор, тот же фильтр тренда
(`C_t > SMA_200(t)`), те же выходы, стоп, размер позиции, лимиты и издержки; вместо условия RSI — случайный выбор
среди инструментов, проходящих фильтры, так, чтобы **число входов в каждом календарном году совпадало** с числом
входов стратегии. Сравнивается ожидаемый R; перцентиль стратегии = доля прогонов с меньшим ожидаемым R.

## 11. Критерии успеха (финальный период, все одновременно)

1. Ожидаемый результат ≥ **+0,10R** на сделку, нижняя граница 90% бутстрэп-интервала **> 0**.
2. Не меньше **100** сделок.
3. Перцентиль относительно случайного контроля ≥ **95**.
4. `costs_x2` на финальном периоде: ожидаемый R > 0; соседние варианты (§9) на валидации в большинстве > 0.
5. Доля исполнимых сигналов ≥ **70%** (с гранулярностью долей, подтверждённой в P1.B).
6. Максимальная просадка `E` ≤ **5%**.

Невыполнение любого пункта → гипотеза отклонена (PLAN §5.7, SCOPE «Критерии остановки»).

## 12. Допущения и ограничения

- **Экс-дивидендные даты известны заранее** (§4.1 п. 5).
- **Аукцион открытия** исполняет LOO полностью по цене открытия, если лимит не ниже неё; очередь и частичные исполнения не моделируются.
- **Стоп-маркет** при гэпе исполняется по цене открытия; внутри дня — ровно по стопу (с издержками модели).
- **Дивиденды** зачисляются в экс-дату, дата выплаты не моделируется.
- **Издержки** — сегодняшний тариф IBKR для всего периода 2006–2026 (в реальности тарифы менялись).
- **Смещение выживших:** бесплатные данные содержат только ETF, торгующиеся сегодня; закрытые фонды тех же категорий
  в набор не попадают. Список таких фондов и оценка влияния — раздел 13 (задача P1.A.07).
- **Данные одного поставщика (Yahoo)**; расхождения со вторым источником проверяются в P1.B.07 и P3.3.06.
