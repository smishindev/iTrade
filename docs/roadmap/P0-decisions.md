## P0.2 Счёт Interactive Brokers (👤 ваши задачи)

> Интерфейс IBKR время от времени меняется. Если какой-то экран выглядит иначе, чем описано, или
> непонятен вопрос — пришлите скриншот (без номеров документов и паролей), разберём вместе.
> Ничего из этого я не могу сделать за вас: это ваша личная заявка с вашими документами.

### [x] P0.2.01 · 👤 Подготовить документы · 0,5 ч
**Шаги:**
1. Удостоверение личности: заграничный паспорт или теудат зеут (скан или чёткое фото).
2. Подтверждение адреса не старше нескольких месяцев: выписка из банка или счёт за коммунальные услуги
   на ваше имя и с вашим израильским адресом.
3. Номер теудат зеут — он же налоговый номер (TIN) Израиля.
4. Под рукой: e-mail, телефон, сведения о работе (работодатель, должность), примерные доход и сбережения.
**Готово, когда:** всё лежит в одной папке на компьютере.

### [x] P0.2.02 · 👤 Подать заявку на счёт · 1–1,5 ч · после: P0.2.01
**Шаги:**
1. Откройте сайт **interactivebrokers.com** → кнопка **Open Account**. Проверяйте адрес: только официальный сайт IBKR.
2. Тип счёта: **Individual** (индивидуальный).
3. Создайте логин и пароль, подтвердите e-mail.
4. Личные данные — латиницей, **точно как в паспорте**. Налоговое резидентство: **Israel**,
   TIN — номер теудат зеут.
5. Работа и финансы — отвечайте честно (доход, капитал, источник средств: зарплата / сбережения).
6. Цели и опыт: укажите реальный опыт. Для обычных акций и ETF требования минимальные.
7. **Важные настройки счёта:**
   - тип счёта **Cash**, а **не Margin** (без кредитного плеча; если по умолчанию стоит Margin — поменяйте);
   - базовая валюта — **USD** (сделки будут в долларах; налоговый пересчёт в шекели делает наша программа);
   - торговые разрешения — только **Stocks → United States** (сюда входят ETF). Опционы, фьючерсы,
     маржу и прочее **не включайте**;
   - тарифный план — **IBKR Pro, Tiered** (наша модель издержек рассчитана на него).
8. **Статус получателя рыночных данных: Non-Professional.** Это частное лицо, торгующее своими деньгами.
   Отвечайте на вопросы анкеты соответственно: статус «профессионала» стоит в разы дороже.
9. **Форма W-8BEN** (входит в заявку): страна — Israel, ставка по договору об избежании двойного
   налогообложения (25% на дивиденды). Подписывается электронно.
10. Загрузите документы из P0.2.01, прочитайте и подпишите соглашения.
**Готово, когда:** заявка отправлена, в личном кабинете статус «на рассмотрении».

### [~] P0.2.05 · 👤 Создать paper-счёт · 0,5 ч · после: P0.2.07
> 7 октября 2026: пока основной счёт не пополнен, создан **IBKR Free Trial** (отдельный демо-счёт,
> не связан с основным). Используем его для IB Gateway и первых задач проверки B, если он работает через API.
> Связанный paper-счёт создаём после пополнения; ответы проверки B, полученные на Free Trial, перепроверяем на нём.

**Шаги:**
1. Client Portal → меню пользователя (иконка человека) → **Settings / Account Settings** → **Paper Trading Account** → создать.
2. Запишите **отдельный логин paper-счёта** (у него свой логин; пароль храните в менеджере паролей, не в файлах проекта).
3. В настройках paper-счёта включите передачу рыночных данных с основного счёта (Share market data), если такая опция есть.
4. Если paper-счёт не активируется без пополнения основного счёта — выполните P0.2.07 с минимальной суммой.
**Готово, когда:** вы можете войти в paper-счёт (например, через веб-платформу IBKR) и видите виртуальный баланс.

### [x] P0.2.06 · 🤝 Установить и настроить IB Gateway · 1 ч · после: P0.2.04
> 7 октября 2026: IB Gateway (Stable) установлен, вход в Free Trial («Simulated Trading») работает; API: порт 4002,
> Read-Only ✓, только localhost ✓, Trusted IP 127.0.0.1 ✓. «Maintain and resubmit orders when connection is restored» = ✓
> (по умолчанию) — решение по нему в P1.B.15. Lock and Exit → **Auto restart в 09:25** (время ПК, Израиль) —
> вне торговой сессии США и вне вечернего окна работы с программой.
**Шаги:**
1. С официального сайта IBKR скачайте **IB Gateway — Stable** для Windows и установите.
2. Запустите, выберите **IB API** и режим **Paper Trading**, войдите логином paper-счёта.
3. **Configure → Settings → API → Settings:**
   - Socket port: **4002** (paper);
   - **Allow connections from localhost only** — включено;
   - Trusted IPs: только `127.0.0.1`;
   - **Read-Only API** — **включено** (выключим только на время задач с заявками в P1.B).
4. Пришлите мне скриншот этого экрана настроек (без логина), я проверю.
**Готово, когда:** IB Gateway запущен в режиме paper, настройки API совпадают с перечисленными.
