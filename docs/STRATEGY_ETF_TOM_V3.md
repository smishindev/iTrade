# Спецификация гипотезы H3 — `ETF_TOM_V3` (эффект смены месяца)

_9 октября 2026, **до любого запуска** H3. Выбор гипотезы и ключевые решения — владелец 9 октября 2026
([spikes/H3-candidates.md](spikes/H3-candidates.md), вариант A): ранний отказ по 2006–2020 целиком, позиция 80% счёта,
базовый SPY, варианты IWM / QQQ / корзина. Параметры — `config/strategies/etf_tom_v3.toml`; версия стратегии — SHA-256
канонического JSON `{"strategy": <параметры>, "universe": <набор>}` (как в H1/H2); журнал и пре-регистрация —
`docs/research-log-H3.md`. Это **последняя из трёх** гипотез (SCOPE)._

**Гипотеза H3.** Доходность широкого американского рынка сосредоточена вокруг смены месяца. Позиция в индексном ETF с
открытия последней сессии месяца до открытия 4-й сессии следующего месяца даёт **больше денег после издержек**, чем
такие же 4-сессионные позиции в случайные дни остальной части месяца, с тем же размером, стопом и издержками.

**Чем отличается от H1/H2.** Там выбирался *инструмент* по графику цены; здесь инструмент один и заранее известен,
выбирается только *время* — по календарю. Уроки H1/H2 учтены: измерение по деньгам счёта, контроль той же частоты и
длительности, издержки при реальном размере.

**Что известно заранее (честно).** Эффект описан в литературе (Ariel 1987; Lakonishok, Smidt 1988; McConnell, Xu 2008)
— он «публичный», после публикации мог ослабнуть. Данные 2006–2020 видены на H1/H2 (другие правила, другие вопросы):
на них смотрели доходности ETF, но не календарные окна. Период 2021–2026 не запускался ни для одной гипотезы.

## 2. Окно смены месяца

Сессии нумеруются по календарю XNYS: в месяце *M* последняя сессия — день **−1**, предпоследняя — **−2**; в следующем
месяце первая — **+1**, вторая — **+2** и т. д.

1. **Вход:** после закрытия сессии, предшествующей дню входа, — заявка **LOO** на открытие дня входа (база: день **−1**),
   лимит `C + 1,0 · ATR20/M` (H1 §4.1, округление вниз до цента). Не исполнилась — окно пропускается (без повторов).
2. **Защитный стоп** (аварийный, у брокера, SCOPE): `C − 3 · ATR20/M` от закрытия сессии решения, GTC.
3. **Выход:** после закрытия дня **+3** — **MOO** на открытие дня **+4** (держим −1, +1, +2, +3: 4 сессии).
4. **Размер:** `q = floor(0,80 · E_t / Lim)` целых акций (по 0,80/N на каждый ETF корзины из N), только на расчётные
   деньги — при нехватке окно пропускается (`settled_cash`), позиция не урезается. Решение — только если член набора.
5. **R** (для отчёта и порога издержек) = результат / `q · (Lim − Stp)`, стоп — аварийный 3 ATR20.
6. Издержки: проверка `RT(q) ≤ 0,10 · q · (Lim − Stp)` (как H2); при позиции ~$2 600 издержки ≈ 0,09% ≈ 0,02R.

Календарь торговых сессий известен заранее (биржа публикует его заблаговременно) — это не заглядывание в будущее.

## 3. Метрики

Как H2 §5: R на сделку с блочным бутстрэпом по месяцу выхода, годовая доходность после издержек, просадка, доля
времени в позиции, ориентиры SPY и равновзвешенный набор (оба — купить и держать, без издержек и налога). Добавочно:
средняя доходность окна в % позиции.

## 4. Случайный контроль (1 000 прогонов на вариант)

В каждом месяце, где у стратегии есть окно, — **одно случайное окно той же длины (4 сессии)**: вход на открытии
случайной сессии месяца *M* с номером от первой до **−5**, выход на открытии через 4 сессии (окно заканчивается до
окна смены месяца). Тот же ETF, размер, лимит, стоп и издержки. Перцентиль = доля прогонов с меньшей итоговой прибылью.
Так контроль отвечает ровно на вопрос гипотезы: «смена месяца лучше обычных дней?».

## 6. Заранее записанные варианты (8 из 20)

| Вариант | Отличие | Тип |
|---|---|---|
| `tom_spy` | база: SPY, вход −1, выход на открытии +4 | кандидат |
| `tom_iwm`, `tom_qqq` | IWM / QQQ вместо SPY | кандидат |
| `tom_basket` | SPY + IWM + QQQ поровну (по 26,7%) | кандидат |
| `tom_entry2` | вход на открытии дня −2 (5 сессий) | кандидат |
| `tom_exit2`, `tom_exit4` | выход на открытии +3 / +5 | кандидат |

Семейства: инструмент (`tom_iwm`, `tom_qqq`, `tom_basket` + база), вход (`tom_entry2` + база), выход
(`tom_exit2`, `tom_exit4` + база).

## 7. Правило выбора и ранний отказ (по 2006–2020)

1. Берётся база `tom_spy`, если только у варианта семейства перцентиль контроля не выше на ≥ **10 пунктов** **и** у всех
   членов его семейства годовая доходность после издержек > 0 (как H2; при нескольких — с бо́льшим перцентилем).
2. **Ранний отказ:** у выбранного годовая доходность ≤ 0 **или** перцентиль контроля < **80** → H3 отклоняется без
   финального запуска.
3. Иначе — финал одной командой: выбранный вариант с контролем 1 000 и `tom_costs_x2` под одним замком.

## 8. Критерии успеха (финальный период, все одновременно)

1. Средний R на сделку > 0, нижняя граница 90% блочного интервала > 0.
2. Не меньше **60** сделок (69 месяцев в финальном периоде).
3. Перцентиль случайного контроля (итоговая прибыль) ≥ **95**.
4. `tom_costs_x2` на финале: годовая доходность > 0; соседи по отбору в большинстве с доходностью > 0.
5. Исполнимых сигналов ≥ **70%**.
6. Максимальная просадка ≤ **20%**.
7. Годовая доходность после издержек > 0 — рядом с SPY и равновзвешенным набором (позиция ~20% времени, поэтому
   обогнать индекс по доходности не ожидается; сравнивается с ним доходность на вложенный доллар).

Невыполнение любого пункта → H3 отклонена; использованы 3 гипотезы из 3 — по SCOPE проект пересматривается.

## 9. Границы проекта

В рамках SCOPE «Границы V1» с изменениями H2 (решения владельца): обычные ETF, только покупки, cash account, вход на
открытии, защитный стоп у брокера, подтверждение каждой сделки. Новое для H3: позиция до 80% счёта на 4–5 сессий,
2 действия владельца в месяц.
